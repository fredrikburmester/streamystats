# Local test stack

Everything needed to run Streamystats end-to-end on one machine, against a
throwaway Jellyfin server, without touching a real media library.

| Piece | Where | Notes |
|---|---|---|
| PostgreSQL (VectorChord) | Docker, `docker-compose.dev.yml` | Same image as production |
| Jellyfin | Docker, `docker-compose.dev.yml` (`--profile jellyfin`) | Pinned by `JELLYFIN_IMAGE_TAG`, default `12.0` |
| Synthetic media | `docker/dev/jellyfin/media/` (gitignored) | Generated by `generate-media.sh` with ffmpeg test patterns + NFO metadata |
| Jellyfin setup | `docker/dev/jellyfin/bootstrap.sh` | Startup wizard, users, libraries, scan, API key |
| App processes | tmux session `streamystats-dev` | job-server + Next.js dev server |

## Quick start

```bash
docker/dev/stack.sh up     # containers + media + Jellyfin bootstrap + DB migrations
docker/dev/stack.sh app    # job-server + Next.js in tmux
docker/dev/stack.sh status
```

Then open the Next.js URL printed by `status`, add the Jellyfin server using
the URL and API key from `docker/dev/jellyfin/.state.env`, and log in as
`admin` / `password`. Regular users are `alice`, `bob`, `carol` (password
`password`).

## Simulating playback

```bash
docker/dev/stack.sh play                          # alice plays a random item for 45s
docker/dev/stack.sh play -u bob -i "Cosmos" -d 90 -c Infuse -m Transcode
docker/dev/stack.sh play -u carol -P              # pauses halfway
```

Sessions appear in Jellyfin's `/Sessions` and are picked up by the session
poller; Jellyfin also logs the playback in its activity log.

## Ports and configuration

`docker/dev/.stack.env` is created on first `up` and is gitignored. Edit it
when a default port is taken:

```
DEV_POSTGRES_PORT=5432
DEV_JELLYFIN_PORT=8096
DEV_NEXT_PORT=3000
DEV_JOB_PORT=3005
JELLYFIN_IMAGE_TAG=12.0     # e.g. 10.11 to regression-test the previous major
```

The app processes get `DATABASE_URL`, `JOB_SERVER_URL`, `SESSION_SECRET` and
`NEXT_SERVER_ACTIONS_ENCRYPTION_KEY` from the shell, which takes precedence
over any `.env` files in the repo.

## Lifecycle

```bash
docker/dev/stack.sh logs 100   # tail both app processes
docker/dev/stack.sh app-stop   # stop the tmux session
docker/dev/stack.sh down       # stop containers, keep data
docker/dev/stack.sh reset      # wipe Postgres + Jellyfin volumes (factory reset)
```

Switching Jellyfin versions: set `JELLYFIN_IMAGE_TAG`, then `reset` and `up`.

## What the synthetic library contains

- 4 movies, one of them (`Elephants Dream`) with two alternate versions in
  the same folder
- 1 series with 2 seasons and 5 episodes, one episode with two alternate
  versions (a Jellyfin 12 feature)
- 1 music album with 3 tracks
- NFO sidecars carry genres, ratings, IMDb/TMDb/TVDb ids, directors, writers
  and actors, so people sync and provider-id matching have data to work with

All files are a few seconds to a couple of minutes of ffmpeg test pattern at
low bitrate. Internet metadata fetchers are disabled on the libraries, so
scans are fast and fully offline.
